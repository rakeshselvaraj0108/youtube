# PREFLIGHT

**Static analysis and CI for video.** *Ship your video like you ship your code.*

A creator uploads to YouTube and only afterwards learns whether the video will
be monetized. By then the first 48 hours — where most of a video's revenue
lives — are gone. There is no dry-run on the most financially consequential
action in the entire creator workflow.

PREFLIGHT is that dry-run. It analyses a video file *before* upload, cites the
specific policy clause behind every finding, shows the adversarial record that
produced the verdict, and **compiles an executable ffmpeg program** that repairs
the video.

Every other tool in the creator ecosystem is a **generator** — make me a
thumbnail, write me a title, cut me a Short. PREFLIGHT is a **verifier**. It is
the missing static-analysis step in a pipeline that currently ships straight to
production with no tests.

```bash
preflight check demo.mp4          # 45/100 · DO NOT PUBLISH · exit 1
preflight fix   demo.mp4 --apply  # 4 operations → demo.safe.mp4 (676ms)
preflight check demo.safe.mp4     # re-analysed, re-scored
```

---

## Quick start

Runs with **no API key**. The default path uses local models and touches no
network.

```bash
make setup     # venv, dependencies, policy corpus
make demo      # generates a clip, then check → fix → check
```

Or by hand:

```bash
pip install -e '.[asr]'
python scripts/build_corpus.py     # author the 14-clause policy corpus
python scripts/make_demo.py        # synthesise a narrated test clip
preflight check samples/demo.mp4 --html
open preflight-out/report.html
```

No footage is committed. Every media artifact is generated by a script, so a
clean clone reproduces the demo without a 40 MB download.

**Requirements:** Python 3.11+, ffmpeg. Docker alternative: `make docker-demo`
— the image bakes the ASR weights in, so it works on a flaky connection.

## What it actually does

```
video.mp4
   │
   ├─ ingest ──────── ffprobe, dual audio extraction, scene-cut keyframes
   │                  content-addressed by BLAKE3
   ├─ speech ──────── faster-whisper, word-level timestamps
   ├─ audio ───────── EBU R128, clipping, dead air, dead-mic, music bed
   ├─ accessibility ─ photosensitive flash detection, captions, speech rate
   ├─ metadata ────── undisclosed paid promotion, description, tags
   │
   ├─ retrieval ───── 14 policy clauses · BM25 ⊕ dense, fused by RRF
   ├─ triad ───────── AUDITOR prosecutes → ADVOCATE defends → ADJUDICATOR rules
   ├─ fusion ──────── cross-modal corroboration, coverage-weighted
   ├─ scoring ─────── five dimensions → Release Readiness
   └─ remediation ─── findings → EDL → 7 optimiser passes → ffmpeg
                      │
                      └─ report.json · report.sarif · certificate.json · report.html
```

## The six claims, and where each one lives

### N1 — Findings are clause-grounded, not guessed

Every finding cites a retrieved passage of the policy corpus verbatim. A tool
that says *"this seems risky"* is not auditable. One that says *"0:34–0:39
matches AF-10's 'casualty figures stated without surrounding framing', here is
the clause, here is the sentence"* is.

→ [`preflight/policy/`](preflight/policy/), [`data/policy/`](data/policy/)

### N2 — The Adversarial Adjudication Triad

A single classification pass over-fires, and an over-firing linter is an
uninstalled linter. Every candidate is contested: AUDITOR prosecutes at
temperature 0.3, ADVOCATE defends using only exemptions the clause documents,
ADJUDICATOR rules at temperature 0 with a calibrated confidence and a written
rationale.

The cascade is also the quota strategy — only windows that produce a candidate
reach stages two and three, so three stages cost far less than three times one.

→ [`preflight/agents/triad.py`](preflight/agents/triad.py)

### N3 — The Remediation Compiler

Findings are compiled, not suggested. They lower into a typed Edit Decision
List; seven optimiser passes run in a fixed order; codegen emits ffmpeg.

Snap-to-word runs *before* coalesce, because coalescing first would merge spans
that word boundaries had not yet widened. The cut budget demotes to MUTE rather
than silently deleting a third of someone's footage.

**If the EDL contains no video ops, the video stream is never re-encoded.** A
15-minute repair becomes a stream copy plus an audio pass.

→ [`preflight/remediate/`](preflight/remediate/)

### N4 — SARIF, exit codes, and a GitHub Action

Findings emit as **SARIF 2.1.0** — what CodeQL and Semgrep speak — so they
render natively in GitHub's Security tab. A video file can fail CI.

SARIF has no time axis. Rather than invent one, seconds stand in for
`startLine` so GitHub renders a position, and true millisecond spans travel in
`properties`. That is a deliberate mapping, not a side effect of copying the
schema.

→ [`action.yml`](action.yml), [`preflight/report/sarif.py`](preflight/report/sarif.py)

### N5 — Content-addressed reproducibility

Every artifact is keyed by BLAKE3 of its inputs. A second run costs **zero API
calls** and produces an identical report. An entry is only a cache hit once a
`.ready` marker is committed, so a run that crashed mid-extraction is a miss
rather than a half-built frame set served as complete.

Measured on the demo clip: **796 ms cold, 30 ms warm, 0 ffmpeg invocations.**

→ [`preflight/cas.py`](preflight/cas.py)

### N6 — The Policy Drift Watcher

> Your back catalogue was compliant when you uploaded it. The rules changed.

```
POLICY DRIFT DETECTED   2026-08-05   2026-08 → 2026-09

CLAUSE  TITLE                              CHANGE        Δ
AF-15   Synthetic and AI-generated content ADDED     1.000
AF-08   Firearms                           MODIFIED  0.252
AF-10   Sensitive events                   MODIFIED  0.190

  semantic delta via embeddings:nvidia/nv-embedqa-e5-v5
  Re-lint 0 of 1 archived videos (selective invalidation)
```

Those deltas are measured, from `make drift`. The archive currently holds one
video, so the re-lint line is honest but unimpressive — selectivity is the
property worth reading, and it needs an archive to be interesting.

Measuring the delta **per changed section** rather than per clause is what makes
this work at all. Moving firearms range content from Yellow to Red — a genuine
tightening — scores **0.023** compared whole-clause, indistinguishable from a
typo and dismissed as cosmetic. The same edit scores **0.252** by section.

The archive records not just clauses a video's findings **cited**, but clauses
retrieval **considered and didn't fire on**. When a clause tightens, the videos
newly at risk are the ones where it was already in contention. Recording only
the former misses exactly those; re-linting everything isn't monitoring, it's a
bill.

Demo it: `make drift`.

→ [`preflight/drift.py`](preflight/drift.py), [`preflight/archive.py`](preflight/archive.py)

## Release Readiness, and why it can be trusted

Five dimensions, all running the same direction — **100 is always good**, so a
90%-full bar means the same thing whether it measures copyright exposure or
caption coverage.

```
overall = min(weightedMean, worst + 15)
```

That clamp is the whole design. The demo video scores **80.2 on a plain weighted
average** — comfortably passing — while its weakest dimension sits at 29.5. The
clamp brings it to **45 / DO NOT PUBLISH**. One fatal flaw is never averaged
away.

The certificate ships the weights and the clamp rule *alongside* the score, so a
client can recompute the number rather than trust it.

**Python and TypeScript must agree.** The page renders one implementation and
`report.json` carries the other; a one-point disagreement makes the certificate
a lie. 52 shared vectors pin them together in both test suites — including the
half-integer cases where `round()` in Python and `Math.round` in JavaScript
disagree.

→ [`preflight/scoring/`](preflight/scoring/), [`src/lib/scoring.ts`](src/lib/scoring.ts)

## Coverage is reported, never hidden

```
coverage 52%   LLM calls 0   elapsed 1344 ms
PARTIAL ANALYSIS — 52% coverage
  impaired: Vision Agent (rate limited, 42% of keyframes)
```

A compliance tool that quietly returns a clean bill of health after inspecting
half its input is worse than no tool. Coverage is a weighted mean over each
agent's share of the analysis surface, and an agent that never ran counts as
zero rather than being dropped from the average.

It surfaces in the header chip, the SARIF invocation, and the certificate.

## How it stays inside a free tier

The community NIM tier sits around 40 requests/minute. The architecture assumes
that:

| Mechanism | Effect |
|---|---|
| Token bucket at 30 RPM | Headroom, so a burst never trips a 429 mid-demo |
| Exponential backoff with jitter | Recovers when one lands anyway |
| Batching | 8 windows per AUDITOR call, not one call per window |
| Cascade | Only windows with a candidate reach ADVOCATE and ADJUDICATOR |
| Read-through cache | Keyed on model + prompt; a re-run costs nothing |
| JSON repair cascade | Models emit prose preambles and trailing commas regardless of instruction |

An 18-minute video costs roughly **15 LLM calls**.

## Honest limits

**This is not YouTube's classifier and cannot be.** The published guidelines are
the specification; the classifier enforcing them is not public. A finding is a
prediction with a citation, not a verdict.

**A copyright non-match does not prove safety.** Content ID's reference database
is private and larger than any public fingerprint service. PREFLIGHT reports
`CLAIM_LIKELY` or `MUSIC_BED_PRESENT` — never `SAFE`.

**Not affiliated with YouTube or Google.** See [COMPLIANCE.md](COMPLIANCE.md)
for the full posture, including the API quota arithmetic and what the tool
explicitly does not do.

```
├── scoring/         fusion, Release Readiness

data/policy/         14 clause files + manifest with per-clause SHA-256
schema/              JSON Schema generated from the TypeScript contract

```

`report.html` is **one self-contained file** — JS, CSS, poster and evidence
frames all inlined, no external references. Double-click it and it works
offline.
